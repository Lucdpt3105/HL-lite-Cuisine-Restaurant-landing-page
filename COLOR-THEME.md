# 🎨 HL Lite Cuisine - Color Theme Guide

## 🌟 New Clean Light Theme

### Primary Colors
```css
--color-primary: #FF6B35    /* Vibrant Orange - Main brand color */
--color-secondary: #FFB347  /* Light Orange - Accents */
--color-accent: #FFA500     /* Gold Orange - Highlights */
```

### Text Colors
```css
--color-dark: #2C2C2C       /* Dark text - Headings */
--color-text: #4A4A4A       /* Medium text - Body */
--color-text-light: #757575 /* Light text - Captions */
```

### Background Colors
```css
--color-background: #FAFAFA /* Very light gray - Page background */
--color-surface: #FFFFFF    /* Pure white - Cards, sections */
--color-border: #E8E8E8     /* Light gray - Borders */
```

### Utility Colors
```css
--color-success: #4CAF50    /* Green - Success messages */
--color-warning: #FFC107    /* Yellow - Warnings */
--color-error: #F44336      /* Red - Errors */
```

## 🎨 Color Usage Guidelines

### Navbar
- **Background**: Orange gradient with blur effect
- **Text**: White (#FFFFFF)
- **Hover**: Lighter white with background
- **Welcome Badge**: White background with orange text

### Buttons
- **Primary**: Orange gradient (#FF6B35 → #FFB347)
- **Text**: White
- **Hover**: Lift effect with shadow

### Cards
- **Background**: White (#FFFFFF)
- **Border**: Light gray (#E8E8E8)
- **Shadow**: Subtle gray shadow
- **Hover**: Orange border

### Typography
- **Headings**: Dark (#2C2C2C)
- **Body**: Medium gray (#4A4A4A)
- **Captions**: Light gray (#757575)

### Sections
- **Odd sections**: White background
- **Even sections**: Light gray background (#FAFAFA)

## 🔥 Orange Variants
- **Primary Orange**: #FF6B35 (Main actions, links)
- **Light Orange**: #FFB347 (Secondary actions, accents)
- **Gold Orange**: #FFA500 (Highlights, badges)

## ✅ Fixes Applied
1. ✅ Clean light theme với màu cam chủ đạo
2. ✅ Text màu đen/xám dễ đọc
3. ✅ Navbar màu cam với text trắng
4. ✅ Welcome badge "Xin chào, [Tên]" hiển thị
5. ✅ Background sáng (#FAFAFA)
6. ✅ Buttons gradient cam đẹp
7. ✅ Shadows subtle, không quá đậm

## 🎯 Design Principles
- **Clarity**: Màu sáng, text contrast tốt
- **Energy**: Cam tươi sáng, năng động
- **Modern**: Gradients mượt, shadows nhẹ
- **Clean**: White space nhiều, thoáng đãng
